# Languages

English (`en`) and Ukrainian (`uk`). English is the source; every string has both.

## Where text lives
- **UI copy**: a `messages.ts` next to the feature (`src/features/builder/messages.ts`, `src/ui/messages.ts`), built with `defineMessages({ en, uk })` from `src/i18n/messages.ts`. The `uk` object is typed from `en`, so a missing key or a wrong signature fails `pnpm typecheck`.
- **Shared counts and words**: `src/i18n/common.ts` (`sets(n)`, `hardSets(n)`, `exercises(n)`, `programs(n)`, `trainingDays(n)`, `days(n)`, `slots(n)`, Undo, Close...).
- **Content**: `data/i18n/uk/` keyed by source ids. `exercises/<family>.json` (`{ "101": { name, aliases, cues } }`), `taxonomy.json`, `equipment.json`, `splits.json`. Source files in `data/` stay English and `taxonomy.json` stays frozen.
- **Not translated**: `features/review` (dev only), `qa.note`, `sources.json` citations, the MCP/HTTP API, the PWA manifest, `llms.txt`.

## How to use it
- In components: `const m = useMessages(featureMessages)`, then `m.title`, `m.moved(name, day)`.
- Outside React (toasts, store callbacks): `getMessages(featureMessages)` at call time, never at module level.
- Names from data: `useCatalog()` already returns localized exercises and templates. For ids use `groupName`, `headName`, `equipmentName`, `equipmentGroupName`, `presetName` from `src/data/localize.ts`.
- Numbers: `formatSets`, `formatWeight`, `setsLabel` in `src/app/format.ts` (locale aware). Dates: `dateFormat(locale, opts)` from `src/i18n/format.ts`. Sorting names: `compareText(locale, a, b)`.
- Days: `dayName(day, style)` in `src/app/days.ts`. Styles `short`, `long`, `letter`, plus sentence forms `on` ("on Monday" / "у понеділок"), `to` ("to Monday" / "на понеділок"), `from` ("from Monday" / "з понеділка").
- Plurals: `plural(locale, n, { one, few, many, other })` from `src/i18n/plural.ts`. Ukrainian needs all four (`other` is for fractions such as 7,5).
- A whole sentence is one message function: `moved: (name: string, day: number) => \`Moved ${name} ${dayName(day, 'to', 'en')}\``. Never glue translated fragments together, never `.toLowerCase()` a name to fit it into a sentence in one language and assume it works in the other.
- Module-level constants built from text (maps, arrays of labels) become functions or `useMemo` with `locale` in the deps.

## Copy rules (both languages)
- Neutral tone, sentence case, no em-dashes.
- English never says "optimal", "under", "maintenance", "risk", "too soon", "overtrained", "recover".
- Ukrainian never says "оптимальн*", "недостатньо", "підтримуюч*", "ризик", "зарано", "перетрен*", "відновл*". No warning words, no advice to cut back.
- Ukrainian uses the apostrophe `ʼ` (U+02BC): `мʼяз`, `пʼятниця`. Quotes are «...».
- Address the reader with the polite plural imperative: «Додайте», «Оберіть», «Тримайте».
- Exercise cues: original, 3-5 short imperative lines, same count as the English record, written from our own English cues only.
